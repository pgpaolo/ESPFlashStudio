## Project status

Current development line: **0.9.0-beta**.

ESP Flash Studio is a portable VB.NET / WinForms workstation for building, packaging, inspecting and flashing ESP32 and ESP8266 firmware using a local PlatformIO / Python / Arduino CLI / esptool toolchain.
